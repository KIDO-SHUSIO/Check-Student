อัปโหลดรายชื่อนักเรียน

เลือกชั้นและห้องเพื่อนำเข้าหรือจัดการรายชื่อนักเรียนใน Google Sheet

รายชื่อนักเรียนตามสถานะการเข้าเรียน
อัปโหลดได้ทั้ง CSV และ Excel (.xlsx, .xls) Apps Script จะสร้าง QR Code และบันทึกเป็นภาพในคอลัมน์ D โดยไม่เรียกบริการ QR ภายนอก

นำเข้ารายชื่อแยกตามห้อง

เลือกชั้นและเลขห้อง แล้วเลือกไฟล์รายชื่อ หากเป็น Excel หลายชีต ระบบจะเลือกชีตที่ชื่อตรงกับห้อง ห้องที่ยังไม่มีจะถูกสร้างให้อัตโนมัติ

ชื่อแท็บชีตหลังอัปโหลด: กรุณาระบุชั้น/ห้อง

ต้องมีคอลัมน์รหัสนักเรียน/เลขประจำตัวและชื่อ-นามสกุล ระบบอ่านตามหัวตารางได้แม้สลับลำดับคอลัมน์ (หากไม่มีหัวตาราง ใช้ A=รหัส · B=เลขที่ · C=ชื่อ)

การอัปโหลดจะแทนที่รายชื่อเดิมของห้องที่เลือกทั้งหมด แต่ประวัติการเช็คชื่อในชีต Attendance จะยังคงอยู่

ยังไม่ได้เลือกไฟล์

รหัสนักเรียนเลขที่ชื่อ-นามสกุลQR Code
ตัวอย่างรายชื่อจะแสดงที่นี่ก่อนอัปโหลด

จัดการห้องและรายชื่อนักเรียน

เลือกชั้นและห้องเพื่อเพิ่ม แก้ไข ลบ หรือย้ายนักเรียน การย้ายห้องจะย้ายประวัติเช็คชื่อด้วย ส่วนการลบจะลบประวัติของนักเรียนคนนั้น

รหัสนักเรียนเลขที่ชื่อ-นามสกุลจัดการ
เลือกห้องเรียนเพื่อแสดงรายชื่อ
