# ระบบเช็คชื่อนักเรียนด้วย QR Code

เว็บแอปเช็คชื่อที่ใช้ Google Sheets เป็นฐานข้อมูลและ Google Apps Script เป็น API
รองรับการสแกน QR ด้วยกล้องหรือเครื่องอ่านบาร์โค้ด การจัดการรายชื่อ การกำหนดครูประจำห้อง
และรายงานจำนวนครั้งมา/ตรงเวลา สาย ลา และขาด

## ไฟล์ในโครงการ

| ไฟล์ | หน้าที่ |
| --- | --- |
| `login.html` | เข้าสู่ระบบและส่งผู้ใช้ไปยังหน้าที่ตรงกับสิทธิ์ |
| `index.html` | หน้าสแกน QR และจัดการคิวส่งข้อมูล |
| `teacher.html` | ครูดูและปรับสถานะนักเรียนประจำห้อง พร้อมดาวน์โหลดบัตร QR |
| `teacher-report.html` | ครูดูจำนวนครั้งของแต่ละสถานะในช่วงวันที่ |
| `upload.html` | ผู้ดูแลอัปโหลด/จัดการห้อง รายชื่อนักเรียน และครูประจำห้อง |
| `admin-report.html` | ผู้ดูแลดูรายงาน โดยเลือกชั้น ห้อง และช่วงวันที่ |
| `Code.gs` | API และการเชื่อมต่อ Google Sheets |

## สิ่งที่ต้องเตรียม

- บัญชี Google ที่เข้าถึง Google Sheets และ Google Apps Script ได้
- เว็บเบราว์เซอร์รุ่นปัจจุบัน แนะนำ Chrome หรือ Edge
- บัญชี GitHub หากต้องการเผยแพร่เว็บผ่าน GitHub Pages
- รายชื่อนักเรียนและข้อมูลครู

## ติดตั้ง Google Sheets และ Apps Script

1. สร้าง Google Spreadsheet สำหรับระบบเช็คชื่อ
2. เปิด **Extensions (ส่วนขยาย) > Apps Script**
3. วางเนื้อหาใน `Code.gs` ลงในโปรเจกต์ Apps Script แล้วบันทึก
4. กลับไปยัง Spreadsheet และโหลดหน้าใหม่ เมนู **ระบบเช็คชื่อ** จะปรากฏ
5. เตรียมชีตตามโครงสร้างนี้

### ชีต `Teacher`

สร้างหัวตารางแถวแรกและใส่ข้อมูลครูตั้งแต่แถวที่ 2:

| คอลัมน์ | ข้อมูล |
| --- | --- |
| A | เลขประจำตัวครู |
| B | ชื่อครู |
| C | ห้องประจำ เช่น `610` |

เลขห้องในคอลัมน์ C เป็นข้อความ เช่น `610` หมายถึง ม.6 ห้อง 10
ห้องครูที่ยังไม่กำหนดให้เว้นคอลัมน์ C ว่างไว้

### ชีต `Attendance`

สร้างหัวตารางแถวแรกตามลำดับคอลัมน์:

| คอลัมน์ | ข้อมูล |
| --- | --- |
| A | วันและเวลาที่เช็คชื่อ |
| B | รหัสนักเรียน |
| C | เลขที่ |
| D | ชื่อ-นามสกุล |
| E | ชั้น/ห้อง เช่น `610` |
| F | สถานะ: `มา`, `สาย`, `ลา` หรือ `ขาด` |

ตั้งคอลัมน์ E เป็นข้อความ (Plain text) เพื่อป้องกัน Google Sheets แปลงเลขห้องเป็นวันที่
หลังตั้งหัวตารางแล้ว ใช้เมนู **ระบบเช็คชื่อ > ตั้งคอลัมน์ห้องใน Attendance เป็นข้อความ**
ได้เช่นกัน

### ชีตรายชื่อนักเรียน

ผู้ดูแลสามารถสร้างห้องและนำเข้ารายชื่อจากหน้าเว็บได้ ชื่อแท็บชีตห้องต้องอยู่ในรูปแบบ
`ม.<ชั้น><เลขห้อง>` เช่น `ม.610` โดยระบบจะสร้างให้เมื่อสร้างห้องหรืออัปโหลดรายชื่อ

โครงสร้างคอลัมน์:

| คอลัมน์ | ข้อมูล |
| --- | --- |
| A | รหัสนักเรียน |
| B | เลขที่ |
| C | ชื่อ-นามสกุล |
| D | QR Code |

หลังเตรียมชีตแล้ว ใน Spreadsheet เลือก **ระบบเช็คชื่อ > ตรวจสอบโครงสร้างฐานข้อมูล**
เพื่อเช็คว่ามีชีตที่จำเป็นครบ

## ตั้งค่า URL ของ Apps Script

1. ใน Apps Script เลือก **Deploy > New deployment**
2. เลือกประเภท **Web app**
3. ตั้งค่า **Execute as** เป็นบัญชีเจ้าของสคริปต์
4. ตั้งค่า **Who has access** ให้ผู้ใช้จากหน้าเว็บเรียก API ได้ โดยทั่วไปต้องเลือก
   **Anyone** หากองค์กรอนุญาต การตรวจสิทธิ์ครู/ผู้ดูแล/เครื่องสแกนจะทำโดยระบบเซสชันของแอป
   ไม่ใช่บัญชี Google ของผู้ใช้แต่ละคน หากนโยบายโรงเรียนไม่อนุญาต anonymous access
   ควรปรึกษาผู้ดูแล Google Workspace ก่อนเผยแพร่
5. เลือก **Deploy** และอนุญาตสิทธิ์ที่ Apps Script ขอ
6. คัดลอก URL ที่ลงท้ายด้วย `/exec`
7. แทนค่า `SCRIPT_URL` ในไฟล์ HTML ทุกหน้าด้วย URL เดียวกัน:
   - `index.html`
   - `login.html`
   - `teacher.html`
   - `teacher-report.html`
   - `upload.html`
   - `admin-report.html`

เมื่อแก้ `Code.gs` หลังจากเผยแพร่แล้ว ให้ไปที่ **Deploy > Manage deployments > Edit**
เลือก **New version** แล้ว Deploy อีกครั้ง การแก้ไฟล์ HTML บน GitHub Pages ไม่ได้เผยแพร่
การเปลี่ยนแปลงใน Apps Script ให้อัตโนมัติ

## เผยแพร่เว็บบน GitHub Pages

1. สร้าง GitHub repository และอัปโหลดไฟล์ HTML ทั้งหมดในโครงการ รวมถึง `README.md`
2. ใน repository เปิด **Settings > Pages**
3. เลือกแหล่งเผยแพร่เป็น branch ที่ต้องการ และโฟลเดอร์ `/ (root)`
4. กดบันทึกและรอ GitHub Pages เผยแพร่เว็บไซต์
5. เปิด URL ของเว็บไซต์ โดยเริ่มใช้งานที่ `login.html`

GitHub Pages ใช้ HTTPS ซึ่งจำเป็นสำหรับสิทธิ์เข้าถึงกล้องบนเบราว์เซอร์
หากใช้ที่อยู่เว็บแบบกำหนดเอง ให้ตรวจว่า HTTPS ทำงานก่อนเริ่มสแกน

## วิธีใช้งาน

### เข้าสู่ระบบ

เปิด `login.html` และใส่เลขประจำตัวครูหรือรหัสเข้าใช้งานที่โรงเรียนกำหนด
ระบบจะพาไปยังหน้าตามสิทธิ์:

- ผู้ใช้สแกน ไปหน้า `index.html`
- ครู ไปหน้า `teacher.html`
- ผู้ดูแล ไปหน้า `upload.html`

เซสชันหมดอายุหลังไม่มีการใช้งานตามเวลาที่กำหนดใน Apps Script
ผู้ใช้สามารถกด **ออกจากระบบ** เพื่อจบเซสชันได้

### ผู้ใช้สแกนเช็คชื่อ

1. เข้าสู่ระบบด้วยรหัสสำหรับเครื่องสแกน
2. เลือกกล้องที่ต้องการ แล้วกด **เปิดกล้อง**
3. อนุญาตให้เว็บไซต์ใช้กล้องเมื่อเบราว์เซอร์ถาม
4. วาง QR ให้อยู่ในกรอบและถือให้นิ่งจนระบบอ่านได้
5. ระบบจะแจ้งทันทีเมื่ออ่าน QR และเก็บรายการไว้ในคิวของอุปกรณ์ จากนั้นส่งข้อมูลไปยัง Google Sheets
6. ตรวจจำนวนรายการที่รอส่ง/บันทึกแล้ว และข้อความสถานะในหน้าจอ

หากกล้องไม่สะดวก ใช้เครื่องอ่านบาร์โค้ดหรือกรอกรหัสนักเรียนในส่วน
**เครื่องอ่านบาร์โค้ด / จัดการคิว** แล้วกด **รับเข้าคิว**

คิวสแกนถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นและจะลองส่งใหม่เมื่อเชื่อมต่อได้
คิวไม่ถูกแชร์ไปยังเครื่องอื่น ควรตรวจว่ารายการรอส่งเหลือศูนย์ก่อนปิดหรือเปลี่ยนอุปกรณ์
สถานะ “สแกนสำเร็จ” หมายถึงอ่าน QR และเก็บเข้าคิวในเครื่องแล้ว
ส่วน “บันทึกแล้ว” จะแสดงเมื่อเซิร์ฟเวอร์ตอบรับ

### ครูประจำห้อง

- หน้า **เช็คชื่อประจำห้อง** แสดงรายชื่อเฉพาะห้องที่ได้รับมอบหมาย เลือกวันที่เพื่อดูสถานะของวันนั้น
- เลือกสถานะ `มา`, `สาย`, `ลา` หรือ `ขาด` จากปุ่มในแถวของนักเรียนเพื่อบันทึก
- ใช้ตัวกรองเพื่อแสดงรายชื่อแยกตามสถานะ
- กด **บัตร QR นักเรียน** เพื่อโหลด QR ของห้อง ดาวน์โหลดรายบุคคลเป็น PNG รวมเป็น ZIP หรือพิมพ์/บันทึกเป็น PDF
- กด **สรุปจำนวนครั้งการเข้าเรียน** เพื่อไปหน้า `teacher-report.html` เลือกวันเริ่มต้นและวันสิ้นสุด แล้วกดแสดงตาราง

### ผู้ดูแลระบบ

#### อัปโหลดและจัดการรายชื่อ

ในหน้า `upload.html`:

1. เลือกระดับชั้นและระบุเลขห้องเพื่อเตรียมห้อง
2. เลือกไฟล์ CSV หรือ Excel (`.csv`, `.xlsx`, `.xls`) ของห้องนั้น
3. ตรวจดูตัวอย่างข้อมูลก่อนอัปโหลด
4. กดยืนยันอัปโหลด รายชื่อเดิมในห้องจะถูกแทนที่ แต่ประวัติใน `Attendance` ยังคงอยู่
5. ใช้ส่วนจัดการห้องเพื่อเพิ่ม แก้ไข ย้าย หรือลบนักเรียน

ไฟล์รายชื่อควรมีรหัสนักเรียน เลขที่ และชื่อ-นามสกุล หากไม่มีหัวตารางระบบใช้
คอลัมน์ A = รหัส, B = เลขที่, C = ชื่อ รายชื่อหนึ่งห้องอัปโหลดได้ไม่เกิน 2,000 คน

การลบนักเรียนจะลบประวัติเช็คชื่อของนักเรียนคนนั้นด้วย การลบห้องจะลบรายชื่อ
และประวัติเช็คชื่อของห้องนั้นด้วย ควรตรวจสอบก่อนยืนยัน

#### กำหนดครูประจำห้อง

ในส่วน **กำหนดครูประจำห้อง** เลือกระดับชั้น เลือกห้อง แล้วเลือกครูได้หลายคน
ครูที่กำหนดแล้วจะไม่สามารถถูกเลือกไปกำหนดห้องอื่นพร้อมกันได้
ข้อมูลครูต้องมีอยู่ในชีต `Teacher` ก่อน

#### รายงานสถานะ

กดปุ่ม **รายชื่อนักเรียนตามสถานะการเข้าเรียน** เพื่อเปิด `admin-report.html`
เลือกชั้น ห้อง ช่วงวันที่ แล้วกด **แสดงตาราง**
ตารางแสดงจำนวนครั้ง `มา/ตรงเวลา`, `สาย`, `ลา`, `ขาด` ต่อคน

รายงานครูและผู้ดูแลไฮไลต์ทั้งแถวตามจำนวนครั้งที่สายภายในช่วงวันที่ที่เลือก:

- สาย 5–6 ครั้ง: แถบสีเหลือง
- สายตั้งแต่ 7 ครั้ง: แถบสีแดง

## กติกาเวลาและสถานะ

เวลาตัดสินสถานะของการสแกนใช้เขตเวลาที่ตั้งค่าใน Apps Script:

- ก่อน 08:20 น.: `มา`
- ตั้งแต่ 08:20:00 ถึง 09:20:59 น.: `สาย`
- หลัง 09:20 น.: `ขาด`

หากครูบันทึกสถานะไว้ก่อนแล้ว การสแกนจะไม่เขียนทับสถานะที่ครูกำหนด
ระบบป้องกันรายการสแกนซ้ำของนักเรียนคนเดิมในวันเดียวกัน
รายการที่ยังไม่มีสถานะในหน้าครูแสดงเป็น **ยังไม่เช็คชื่อ** ไม่ได้ถูกนับเป็น `ขาด` โดยอัตโนมัติ

## ข้อมูลและความปลอดภัย

- ข้อมูลนักเรียนและประวัติการเข้าเรียนอยู่ใน Google Sheets ของโรงเรียน
- จำกัดสิทธิ์แชร์ Spreadsheet และ Apps Script ให้เหมาะกับผู้รับผิดชอบ
- อย่าใส่รหัสผ่าน, access code จริง, token หรือข้อมูลส่วนบุคคลลงใน README หรือ repository สาธารณะ
- `Code.gs` มีรหัสเข้าใช้งานของผู้ดูแลและเครื่องสแกนเป็นค่าคงที่ใน source code
  ต้องเปลี่ยนเป็นรหัสที่คาดเดายากและไม่ซ้ำก่อนใช้งานจริง และห้ามเผยแพร่ repository
  แบบสาธารณะจนกว่าจะเอารหัสจริงออกจาก source code หรือย้ายไปเก็บใน Script Properties
- URL ของ Web App ไม่ใช่ข้อมูลลับ แต่ token สำหรับเซสชันเป็นข้อมูลชั่วคราวและไม่ควรเผยแพร่
- การอัปโหลด CSV/Excel ใช้ไลบรารี SheetJS จาก CDN; หน้าเครื่องสแกนใช้ไลบรารี QR จาก CDN
  ผู้ใช้ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดหน้าเว็บและติดต่อ Apps Script

## การแก้ปัญหา

| อาการ | วิธีตรวจสอบ |
| --- | --- |
| เข้าสู่ระบบไม่ได้ | ตรวจเลขประจำตัวครูในคอลัมน์ A ของ `Teacher` และตรวจ URL `/exec` ในทุกหน้า |

| สแกนแล้วข้อมูลยังรอส่ง | ตรวจอินเทอร์เน็ต อย่าล้างข้อมูลเว็บไซต์หรือ localStorage ของอุปกรณ์นั้น แล้วรอให้คิวส่งใหม่ |
| ห้องหรือวันที่ในรายงานไม่ตรง | ตรวจค่าห้องในคอลัมน์ E ของ `Attendance` ให้เป็นข้อความและเลือกช่วงวันที่ที่ถูกต้อง |
| Apps Script ตอบว่าไม่มีคำสั่งหรือ backend เก่า | วาง `Code.gs` รุ่นล่าสุดแล้ว Deploy เป็น New version และตรวจว่า HTML ทุกหน้าชี้ URL เดียวกัน |
| QR ไม่อ่าน | ทำความสะอาดเลนส์ เพิ่มแสง ลดแสงสะท้อน ถือบัตรให้นิ่ง และให้ QR อยู่ในกรอบอย่างชัดเจน |
