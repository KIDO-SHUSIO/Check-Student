# คู่มือใช้งานระบบเช็คชื่อนักเรียน

คู่มือนี้อธิบายวิธีใช้งานสำหรับครูประจำห้องและผู้ดูแลระบบ

## เข้าสู่ระบบ

1. เปิดหน้าเข้าสู่ระบบของโรงเรียน
2. กรอกข้อมูลเข้าสู่ระบบที่ได้รับ
3. ระบบจะเปิดหน้าตามสิทธิ์ของผู้ใช้
   - ครูประจำห้อง: หน้าเช็คชื่อประจำห้อง
   - ผู้ดูแลระบบ: หน้าอัปโหลดและจัดการรายชื่อนักเรียน
4. เมื่อใช้งานเสร็จ ให้กด **ออกจากระบบ**

## ครูประจำห้อง

### เช็คชื่อและดูรายชื่อนักเรียน

1. เปิดหน้า **เช็คชื่อประจำห้อง**
2. เลือกวันที่ที่ต้องการตรวจสอบ
3. ตรวจรายชื่อนักเรียนและสถานะของแต่ละคน
4. หากต้องการบันทึกหรือแก้ไขสถานะ ให้เลือก **มา**, **สาย**, **ลา** หรือ **ขาด** ในแถวของนักเรียน
5. ใช้ตัวกรองเพื่อดูรายชื่อตามสถานะ

ระบบกำหนดสถานะการสแกนตามเวลา: ก่อน 08:20 น. เป็น **มา**, ตั้งแต่ 08:20 ถึง 09:20 น. เป็น **สาย** และหลัง 09:20 น. เป็น **ขาด** หากครูบันทึกสถานะไว้แล้ว การสแกนจะไม่เปลี่ยนสถานะนั้น

### ดาวน์โหลด QR Code

1. กด **บัตร QR นักเรียน**
2. เลือกดาวน์โหลด QR รายคนเป็น PNG, ดาวน์โหลดทั้งห้องเป็น ZIP หรือพิมพ์/บันทึกเป็น PDF
3. ตรวจสอบรายชื่อและ QR ก่อนส่งบัตรให้นักเรียน

### ดูสรุปการเข้าเรียน

1. กด **สรุปจำนวนครั้งการเข้าเรียน**
2. เลือกวันเริ่มต้นและวันสิ้นสุด
3. กดแสดงตารางเพื่อดูจำนวนครั้งที่นักเรียนแต่ละคน **มา/ตรงเวลา**, **สาย**, **ลา** และ **ขาด**

แถวของนักเรียนที่สาย 5–6 ครั้งจะแสดงเป็นสีเหลือง และตั้งแต่ 7 ครั้งขึ้นไปจะแสดงเป็นสีแดง โดยนับตามช่วงวันที่ที่เลือก

## ผู้ดูแลระบบ

### อัปโหลดรายชื่อนักเรียน

1. เปิดหน้า **อัปโหลดรายชื่อนักเรียน**
2. เลือกระดับชั้นและระบุห้อง
3. เลือกไฟล์ CSV หรือ Excel (`.csv`, `.xlsx`, `.xls`)
4. ตรวจสอบตัวอย่างรายชื่อและข้อมูลให้ถูกต้อง
5. กดยืนยันอัปโหลด

ไฟล์ควรมีรหัสนักเรียน เลขที่ และชื่อ-นามสกุล หากไม่มีหัวตาราง ระบบจะอ่านคอลัมน์ A เป็นรหัสนักเรียน คอลัมน์ B เป็นเลขที่ และคอลัมน์ C เป็นชื่อ-นามสกุล รองรับนักเรียนไม่เกิน 2,000 คนต่อห้อง

การอัปโหลดรายชื่อใหม่จะแทนที่รายชื่อเดิมของห้องนั้น โปรดตรวจสอบไฟล์และห้องให้ถูกต้องก่อนยืนยัน

### จัดการห้องและรายชื่อนักเรียน

ใช้ส่วนจัดการห้องเพื่อเพิ่ม แก้ไข ย้าย หรือลบนักเรียนและห้อง โปรดตรวจสอบรายการก่อนยืนยันการลบ เพราะการลบนักเรียนหรือห้องจะลบประวัติการเข้าเรียนที่เกี่ยวข้องด้วย

### กำหนดครูประจำห้อง

1. ไปที่ส่วน **กำหนดครูประจำห้อง**
2. เลือกระดับชั้นและห้อง
3. เลือกครูที่ต้องการกำหนด แล้วบันทึก

สามารถกำหนดครูได้หลายคนต่อห้อง แต่ครูที่ได้รับมอบหมายแล้วจะไม่สามารถถูกกำหนดให้ห้องอื่นพร้อมกันได้

### ดูรายงานสถานะ

1. กด **รายชื่อนักเรียนตามสถานะการเข้าเรียน**
2. เลือกระดับชั้น ห้อง วันเริ่มต้น และวันสิ้นสุด
3. กด **แสดงตาราง**

ตารางแสดงจำนวนครั้งที่นักเรียนแต่ละคน **มา/ตรงเวลา**, **สาย**, **ลา** และ **ขาด** ในช่วงวันที่เลือก แถวที่สาย 5–6 ครั้งเป็นสีเหลือง และตั้งแต่ 7 ครั้งขึ้นไปเป็นสีแดง

## หากพบปัญหา

- **ครูไม่เห็นห้องหรือรายชื่อ:** ติดต่อผู้ดูแลระบบเพื่อตรวจสอบการกำหนดห้องและรายชื่อ
- **เข้าสู่ระบบไม่ได้:** ตรวจสอบข้อมูลเข้าสู่ระบบที่ได้รับ หรือติดต่อผู้ดูแลระบบ
- **รายงานไม่แสดงข้อมูล:** ตรวจสอบระดับชั้น ห้อง และช่วงวันที่ แล้วลองแสดงตารางอีกครั้ง
- **อัปโหลดไม่สำเร็จ:** ตรวจชนิดไฟล์ ข้อมูลในไฟล์ และห้องที่เลือก
- **QR Code อ่านยาก:** ทำความสะอาดเลนส์ เพิ่มแสง ลดแสงสะท้อน และถือบัตรให้นิ่ง
